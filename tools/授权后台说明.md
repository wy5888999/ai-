# 授权后台使用说明

## 分工

- **你**：运行后台，看到期、开户、按月续费
- **客户**：只拿登录窗口（推荐发 exe）

## 启动后台（你自己电脑 / 云服务器）

```bat
cd F:\EA\tools
start_admin.bat
```

打开 http://127.0.0.1:8787/admin  
默认管理员 admin / admin123

### 远程给客户用时

1. 后台电脑防火墙放行 **8787** 端口（或路由器端口转发）。
2. 编辑 `data\config.json`：
   - `"server_host": "0.0.0.0"`（已默认，允许外网连入）
   - `"client_server_url": "http://你的公网IP:8787"`
3. 客户窗口/exe 里「服务器」填同一个地址。

## 打成客户 exe（推荐分发方式）

```bat
cd F:\EA\tools
build_auth_exe.bat
```

完成后把文件夹发给客户：

`tools\dist\授权工具_分发\`

里面有：
- `授权工具.exe`（双击即开窗口，无黑框）
- `data\client_config.json`（可预填服务器地址）
- `客户使用说明.txt`

客户**不需要**安装 Python。

## 本机调试客户窗口

```bat
cd F:\EA\tools
start_client.bat
```

## 续费规则

从「当前到期日」和「今天」里较晚的那天起，再加 30 天 × 月数。
