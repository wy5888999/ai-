DeepSeek 报 timeout / HTTP 503 时怎么办（给客户）

原因：DeepSeek 云端忙或网络慢，不是 EA 坏了。

必做：
1) 每人用自己的 API Key（不要多人共用一个 Key）
2) 配置里用 deepseek-v4-pro（全程 Pro；超时可把 timeout_sec 再加大）
3) 保持桥接窗口开着；失败会自动重试，偶发 503 等几分钟即可

data/deepseek_config.json 建议：
  "model": "deepseek-v4-pro"
  "fallback_model": "deepseek-v4-pro"
  "timeout_sec": 90
  "max_tokens": 512
  "api_retries": 3
  "api_retry_sleep_sec": 2

长期仍不稳：换其它兼容 OpenAI 接口的中转，修改 base_url。
